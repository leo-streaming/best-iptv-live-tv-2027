## What Is IPTV?

**Internet Protocol Television (IPTV)** is a television delivery technology that distributes video over internet protocol networks instead of relying exclusively on traditional cable or satellite broadcasting.

IPTV can include:

**Live IPTV:** Television channels playing scheduled programming in real time.

**Video on Demand (VOD):** Movies and television episodes available for selection whenever the viewer wants to watch.

**Time-Shifted Television:** Features that allow viewers to replay or catch up on previously broadcast programs, where supported.

**Electronic Program Guide (EPG):** A digital schedule showing current and upcoming programs.

### IPTV vs Traditional Cable

| Feature | IPTV | Traditional Cable |
|---|---|---|
| Delivery | Internet connection | Cable network |
| Live TV | Supported | Supported |
| Video on demand | Depends on provider | Depends on package |
| Smart TV support | Often available | Varies |
| Mobile streaming | Often available | Depends on provider |
| Local channels | Varies by rights and region | Typically market-specific |
| Connection requirements | Broadband internet | Cable infrastructure |
| Content licensing | Must be verified | Typically established by operator |

The IPTV technology itself is legal. Individual services must have the appropriate rights to distribute the programming they provide.

## M3U vs Xtream Codes

IPTV services may support different methods for configuring compatible streaming applications.

### What Is an M3U Playlist?

An **M3U playlist** is a file or URL containing media stream references.

Compatible IPTV players can use these references to display channel playlists.

### What Are Xtream Codes Credentials?

Xtream Codes-style login typically uses:

- Server URL
- Username
- Password

Compatible applications use these credentials to retrieve available channels and associated content.

### What Is an EPG?

An **Electronic Program Guide** displays scheduled television programming.

Depending on the player and service, it may show:

- Channel names
- Current programs
- Future programs
- Program descriptions
- Broadcast times

### M3U vs Xtream Codes Comparison

| Feature | M3U Playlist | Xtream Codes API |
|---|---|---|
| Setup | Playlist URL or file | Server and login credentials |
| Live channels | Supported | Supported |
| VOD organization | Player-dependent | Often supported |
| EPG | Separate or integrated | Often integrated |
| Compatibility | Depends on player | Depends on player |
| Updates | Provider-dependent | Provider-dependent |

Neither method guarantees better streaming quality on its own.
